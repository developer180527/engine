backed by tests that actually exercise them — 4 hardened, 7 working, 3
prototype. Evidence was derived by mapping each test's includes to the
subsystem it touches, not by assumption.

  cooked scenes — have never been fuzzed. Volume of tests is not adversarial
  coverage. Recorded at `working` with the blocker named: a scene-deserializer
  fuzz target, already next in the testing plan.

  assetlib::loadMesh, not runtime code, so citing it as runtime evidence would

  which lives at src/scene/. Fixed.
- modules/hid is a git SUBMODULE — bootstrap had written front-matter into
  another repo. Reverted; the doctor now skips submodules by design, because
  this tool must not gate or edit files another project owns. hid gets
  classified in its own repo.

Tool corrections the work forced:
- `hardened` now requires ≥1 fuzz/soak/stress test ALWAYS (a pure-logic
