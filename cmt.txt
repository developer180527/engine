infra: machine-checked doc contract, generated status, tier ladder

Documentation drifts silently and "stable" was a matter of opinion. Two
recent examples: a design doc advertised a 107 ms cache restore that held
only on the day it was measured, and engine_cook reported "0 cooked" after
every successful cook for weeks. Review didn't catch either, because review
reads intent. This makes the tree the authority.

scripts/engine_doctor.py (stdlib only, no pip dependency):
  check   — every doc's front-matter against the tree: covers/tests paths
            exist, tier claims have evidence, and `as-built` docs whose code
            changed after their `verified:` date are STALE (git decides).
  status  — regenerates ENGINE_STATUS.md, the one generated answer to "what
            is actually true right now"; `--check` fails when out of date,
            the way a formatter does.
  bootstrap — placeholder front-matter for new docs. Writes `unreviewed`
            rather than guessing: fabricated metadata is worse than none
            because it looks checked.

docs/engineering-standards.md defines the contract and the tier ladder
(prototype/working/hardened/production), each tier's evidence mechanical.
Two deliberate consequences: a subsystem that parses external input cannot
reach `hardened` without a fuzz/soak test, and a stale doc caps the tier —
if nobody re-verified the description, nobody knows what it does.

No dates in the ladder: deadlines coordinate people, and the actual problem
was not knowing which parts were trustworthy. "hardened by Friday" is still
sayable, but now Friday has an unambiguous answer.

Adoption: 49 docs placed under contract; 4 subsystems classified with real
evidence (src/assets, modules/assetlib hardened; src/core/memory,
src/runtime/jobs working); 11 still prototype/unreviewed — visible on
purpose. Missing front-matter is a warning so adoption is incremental; flip
CI to --strict-missing --warnings-as-errors once unreviewed hits zero.

Checker verified against deliberate violations (stale date, broken covers
path, hardened-without-tests) — each caught, tree restored. Wired as
`ctest -L docs` and a CI step on the gating leg.
