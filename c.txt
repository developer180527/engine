tests: pin the overflow, and record the seven defects that were fixed

Two follow-ups to the last three commits, both small and both closing loops
those commits left open.

── the overflow had no regression test ─────────────────────────────────────
params_fit_their_uniforms was widened to u64 and nothing pinned it, which by
this repo's own rule means it is not fixed yet: a bug is fixed when a test fails
without the change and passes with it.

The test covers BOTH bounds checks, because the defect was never the arithmetic
— it was two sibling functions drifting apart in one sitting, one widened and
one not. Pinning only the one that broke leaves the drift free to run the other
way. Boundaries either side are asserted too (a float at component 3 fits
exactly, component 4 spills), so the fix cannot degrade into "reject
everything".

Mutation-proven in BOTH profiles, with the two distinct signatures that made
this dangerous:

  debug     attempt to add with overflow            (shader.rs:177)
  release   offset u32::MAX with Float must be REJECTED

Release is the one that mattered — pre-fix it returned Ok.

Ledger at 21: memory 4, logic 6, coverage 4, threading 3, abi 2, build 2.

Two are written to be uncomfortable rather than tidy. BUG-0016 is BUG-0004's
exact shape three weeks later — a check that exists, is believed to run, and
does not — and its note records that I verified two of those four lanes by hand
with --nocapture and then failed to make the check mechanical. BUG-0017 is the
self-agreeing-check pattern this crate exists to replace, reintroduced inside it.

BUG-0021's proof records the METHOD: found by grepping for the pattern rather
than waiting for CI. The build stops at the first error, so CI could only ever
report one of four — three more red runs to find them one at a time.

── the gate's blind spot, now written down ─────────────────────────────────
engine_doctor validates entries that EXIST and structurally cannot notice one
that should exist and does not. Three commits fixing seven defects landed before
anyone spotted it, and only because someone went looking. "A fix and its entry
land together" is a human rule and nothing will ever tell you it was skipped.
