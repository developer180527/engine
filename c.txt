copy was "safe only while miniaudio uses this path to GROW" — exactly inverted,
since growing is the unsafe direction. Identifying a hazard and drawing the
opposite conclusion is worse than not considering it: nothing executable
disagreed with something that read as reasoned.

BUG-0023 is recorded as NOT FIXED. The sanitizer exclusion is correct in itself
— the Rust harness aborts under a dlopen'd instrumented module — but its
consequence was never noticed: the provider's only behavioural coverage lives in
the excluded test, so that whole TU sits outside ASan's reach, which is why a
textbook heap over-read survived to a Linux SIGSEGV. Both remedies (nightly
-Zsanitizer, or a C++ harness linking the provider directly) are real work and
deserve their own pass rather than a patch smuggled in here.

BUG-0025's proof notes that TSan found one race and READING found the other. A
report bounds what the tool observed in one run; it is a starting point, not a
complete list.
