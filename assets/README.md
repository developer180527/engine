# Engine assets

3D models for the engine to load.

Bundled: Duck.gltf is the canonical Khronos sample model, ~200KB,
known-good test asset for verifying the glTF loader.

Add your own .gltf or .glb files to this folder. The asset browser
panel will list them.

.blend files need Assimp (not integrated yet). Export from Blender
as glTF 2.0 instead.
